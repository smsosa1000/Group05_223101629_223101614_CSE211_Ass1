About CSE211 Web Programming

This course introduces students to the principles and practices of modern web application development. The curriculum covers the complete lifecycle of building web applications, from design and front-end implementation with HTML5 and CSS3, to adding interactivity with JavaScript, and developing dynamic front-end applications using React. On the server side, students will use Node.js and the Express.js framework to design and implement RESTful APIs, integrate with relational databases (SQLite/Postgres), and manage data-driven workflows. Emphasis is placed on responsive design, accessibility, security, and industry-standard development tools and practices. By the end of the course, students will have built and deployed a full-stack web application to the cloud, gaining both practical skills and real-world project experience.

Course Objectives

  1. Design and develop responsive, and semantically structured websites using modern HTML5 and CSS3, including Flexbox and Grid layouts, and responsive design techniques.
  2. Implement interactivity with modern JavaScript (ES6+), including the Document Object Model (DOM) manipulation, events, form validation, API integration, and create interactive user experiences.
  3. Build front-end applications using React with components, state management, and client-side routing.
  4. Develop server-side applications and RESTful APIs using Node.js and the Express framework.
  5. Integrate databases (SQLite/Postgres) with web applications to perform Create, Read, Update, and Delete (CRUD) operations.
  6. Apply web standards including the fundamentals of HTTP, accessibility guidelines (WCAG 2.2), and web security practices (HTTPS, CORS, authentication, JWT).
  7. Use modern development tools and workflows, including Git/GitHub for version control, VS Code for development, and deployment pipelines for cloud-based applications.
  8. Evaluate and optimize web applications for performance and user experience using Core Web Vitals and accessibility audits.

Topics Covered

  • Introduction to the Internet, WWW, and HTTP/HTTPS.
  • Foundations of the Web: HTML, CSS, JavaScript, Client-side programming.
  • HTML5 document structure, semantic elements, multimedia, forms, and advanced responsive design.
  • Styling with CSS: Cascading Style Sheets, Flexbox, Grid, transitions, animations.
  • JavaScript Fundamentals: Variables, functions, DOM manipulation, events, asynchronous operations.
  • Server-Side Programming with Node.js, Express, APIs, and data handling (JSON).
  • Database Integration: SQL/NoSQL, CRUD operations.
  • Front-end Frameworks: React (components, state, routing).
  • Deployment and Web Trends: Docker, Vercel/Netlify, PWAs, Service Workers, WebSockets.
  • Security: HTTPS/TLS, Cookies vs JWT, Sessions, CORS, OWASP basics.
  • Performance & Accessibility: Core Web Vitals (LCP, CLS, FID), audits.

Course Benefits

By completing this course, students will gain hands-on experience in building full-stack web applications, preparing them for real-world development roles. Benefits include mastering industry-standard tools like Git, VS Code, React, Node.js, and databases; understanding security and performance best practices; and deploying projects to platforms like Vercel or Netlify. This course also emphasizes collaboration through group projects and provides a portfolio piece via the final full-stack application.

Our mission is to provide quality education through innovative web technologies, fostering skills for the digital future.
